This GodotFest 2026 talk explores how solo developers and small teams can create leverage in three ways: integrate existing ecosystems instead of rebuilding them, automate repeated work, and move up the stack by making powerful tools easier to use.

Drawing from his work at TecunHuman, Werner Mendizabal traces that process from a need for dynamic music through Csound, DISTRHO, LV2, and VST3 integration; reproducible cross-platform builds and releases; and Godot tools that make creating and using audio plugins easier. The talk connects this shared infrastructure to real games, an experimental automated art pipeline, and the idea that publishing reusable code, environments, documentation, and knowledge can give the indie game community a shared stack on which to build.
