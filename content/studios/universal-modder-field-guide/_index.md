Universal Modder Field Guide is an independent documentation project maintained through the GitHub account [yuzhousiwei](https://github.com/yuzhousiwei). Its resources cover coding-agent setup, game-specific development routes, version checks and mod-loading diagnostics.

This profile identifies the publisher of the contributed tutorial. It does not claim to be a registered game studio or the official Universal Modder project. It is not affiliated with Mojang, Microsoft, NeoForge or Fabric.
